# pharma-regulation-site

[pharma-regulation](https://github.com/nawoonkim423/pharma-regulation)이 매일 생성하는
규제 업데이트 사이트의 배포용 저장소.

이 저장소에는 빌드 결과물만 들어온다. 수집·분석 코드와 리포트 원문은 비공개
저장소에 있다. GitHub Free 플랜에서 비공개 저장소는 Pages를 쓸 수 없어,
공개할 산출물만 여기로 분리했다.

**사이트**: https://nawoonkim423.github.io/pharma-regulation-site/
